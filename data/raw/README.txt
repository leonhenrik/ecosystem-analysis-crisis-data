# Crisis Data Funding Compass - Data Export

Export Date: September 14, 2026 at 08:33 AM GMT-4

## About This Dataset

This export contains data from the Crisis Data Funding Compass, an overview of the crisis data funding ecosystem. The dataset includes information about organizations providing crisis data products and services, along with details about their specific assets/projects. The data set is subject to expansion and correction.

## Export Contents

This export includes two CSV files:

1. organizations.csv - Information about data provider organizations
   - Organization Name
   - Organization Type
   - Description
   - Supporting Donors (donor donors funding the organization)
   - Investment Types (types of data assets provided)

2. assets.csv - Information about specific data products/projects
   - Asset Name
   - Organization Name (provider)
   - Investment Types
   - Investment Themes
   - Supporting Donors
   - Description
   - Website

## Current View Filters

This export contains the complete dataset with no filters applied.

## Data Notes

- Multiple values in a single field are separated by semicolons (;)
- Empty fields indicate that information was not available
- Supporting Countries refers to donor countries that fund the organization or asset
- For assets without specific donor information, organization-level donors are used
